🐧 Linux Komut Laboratuvarı

Tarayıcıda sanal bir terminal. Görevleri sırayla tamamla, komutları kendin dene.

İpuçları: ↑ / ↓ ile geçmiş komutlar, Tab ile dosya adı tamamlama. "help" yazarak komut listesini görebilirsin. Dosyalar bu tarayıcıda saklanır.

Görevler

Komut özeti

  • help / man komut — yardım ve kılavuz
  • pwd — bulunduğun dizinin yolunu göster
  • cd dizin — dizin değiştir (cd .. üst dizin, cd ~ ev dizini)
  • clear — ekranı temizle
  • ls [-la] — dizin içeriğini listele (-a gizli, -l ayrıntılı)
  • mkdir [-p] ad — dizin oluştur
  • touch dosya — boş dosya oluştur
  • echo metin > dosya — dosyaya yaz (>> ile sona ekle)
  • cat dosya — dosya içeriğini göster
  • more dosya / less dosya — sayfa sayfa göster
  • cp [-r] kaynak hedef — kopyala
  • mv kaynak hedef — taşı / yeniden adlandır
  • rm [-r] ad — sil (geri alınamaz!)
  • grep [-i] desen dosya — desen içeren satırları bul
  • chmod 755 dosya / chmod +x dosya — izin değiştir
  • find . -name "*.txt" — ada göre ara
  • cal / date — takvim ve tarih
  • which ls / whereis ls — komutun konumu
  • wc -l dosya — satır sayısını say
  • dd if=/dev/zero of=dosya bs=512 count=4 — blok kopyalama
  • uname -a, uptime, free, df -h — sistem bilgisi
  • whoami, sudo -i (root), exit — kullanıcı ve yetki
  • nano dosya — metin düzenle (Ctrl+O kaydet, Ctrl+X çık)
  • ps, top, kill PID — süreçler
  • sudo adduser ad / sudo deluser ad — kullanıcı yönetimi
  • tar -czf a.tar.gz dizin / tar -xzf a.tar.gz — sıkıştır ve aç
  • systemctl status|start|stop|restart ad — servis yönetimi
  • sudo apt update / sudo apt install paket — paket kurma
  • ip a, ping host, ss -tuln — ağ komutları
  • sudo reboot / sudo shutdown -h now — yeniden başlat / kapat
  • Dosya ve dizin: tree du stat file basename dirname realpath ln -s nl
  • Metin işleme: sort uniq diff cmp cut sed printf seq base64
  • Kullanıcı ve yetki: id groups passwd who last w chown useradd usermod groupadd umask
  • Ortam: env printenv export alias type
  • Süreç ve sistem: pstree killall vmstat lscpu lsblk nproc mount journalctl dmesg crontab -l timedatectl hostnamectl
  • Ağ: dig nslookup traceroute curl wget ssh lsof -i iptables -L ufw ip route
  • Paket, servis ve sıkıştırma: apt dpkg -l service systemctl gzip gunzip tar md5sum sha256sum
Eğitim amaçlı sanal ortam. Gerçek bilgisayarınızdaki dosyalara ve süreçlere dokunmaz.
